# 木搭图（Modatu）产品术语表

> 统一中文/英文对照与定义，供开发、UI 设计、测试与文档使用。
> 「来源」列标注术语产生位置：**现有** = 已实现代码；**v2 UI** = Figma 风格改版引入/重命名的概念。

## 1. 全局与数据概念

| 中文 | 英文 | 解释 | 来源 |
| --- | --- | --- | --- |
| 木搭图 | Modatu | 产品名。Web 端铝型材家具设计工具。 | 现有 |
| 设计 / 项目 | Design / Project | 一份用户设计文件，含模型 JSON 与版本历史；URL 为 `/editor/:id`。二者混用时优先用「设计」。 | 现有 |
| 设计模型 | Design Model | 设计的数据结构（`meta` + `profiles` + `panels`），受 Schema 校验约束。 | 现有 |
| 知识库 / 目录 | Catalog | 服务端下发的数据快照：型材规格、连接件、兼容矩阵、板材、颜色、安全规则。 | 现有 |
| 型材规格 | Profile Spec | 某型号铝型材的定义：截面、宽高、槽宽、每米重量、承重表、切割长度范围、价格。如「3030」。 | 现有 |
| 型材 | Profile | 画布中的一根型材**实例**（引用某规格 + 切割长度 + 位置 + 朝向 + 颜色）。 | 现有 |
| 封板 / 板件 | Panel | 场景中的板（层板、背板等），引用板材材质 + 厚/宽/高 + 平面。 | 现有 |
| 板材 | Panel Material | 板的材质知识库条目（多层实木板、亚克力板等），含常用厚度列表。 | 现有 |
| 连接件 | Connector | 型材之间连接所用配件（角码、螺栓等）的知识库条目。 | 现有 |
| 兼容矩阵 | Compatibility | 「规格 A × 规格 B → 可用连接件」的查询关系。 | 现有 |
| 颜色 / 表面处理 | Finish | 型材颜色条目（本色/黑色/原木色等），含代表色 `colorHex` 与价格。 | 现有 |
| 安全规则 | Safety Rule | 规则化设计提示（如跨度-承重超限），在属性面板实时求值展示。 | 现有 |
| 截面 | Cross-section | 型材横断面几何环数据（外轮廓 + 孔洞），来源为 DXF 导入或参数化近似。 | 现有 |
| 切割长度 | Cut Length | 一根型材实例沿挤出方向的长度（mm），受规格 min/max 约束。 | 现有 |
| 朝向 | Orientation | 型材挤出轴方向：`立柱 Y` / `沿 X` / `沿 Z`。 | 现有 |
| 最小角点定位 | Min-corner Positioning | 位置语义：`position` 为部件包围盒在 X/Y/Z 最小角的坐标。 | 现有 |

## 2. 界面区域

| 中文 | 英文 | 解释 | 来源 |
| --- | --- | --- | --- |
| 编辑器 | Editor | 设计主界面：画布 + 工具轨/浮动面板 + 属性面板 + 浮动 chrome。 | 现有 |
| 画布 / 预览窗口 | Canvas / Preview（Viewport） | 中央 3D 视图区域（Three.js），旋转/缩放/拾取/拖拽都发生在这里。 | 现有 |
| 工具栏 | Toolbar | 画布底部居中的深色浮动工具条：选择、放置、适配视图、清单（BOM）、AI。 | v2 UI |
| 工具轨 | Rail | 画布左缘默认折叠的窄图标条（仅 icon + padding 宽度）：选择工具 + 型材库/部件/插入三个入口。点击图标展开浮动面板，让画布默认占满更大宽度。 | v2 UI |
| 浮动面板 | Floating Panel | 点击工具轨图标后在画布左侧展开的悬浮卡片，按激活分区显示型材库 / 部件 / 插入内容。 | v2 UI |
| 文件卡 | File Card | 画布左上浮动卡片：产品标 + 设计名（双击重命名）+ 保存状态。 | v2 UI |
| 操作组 | Action Group | 画布右上浮动卡片：撤销、重做、版本历史、用户头像（下拉：我的设计/管理后台/登出）。 | v2 UI |
| 属性面板 | Properties Panel | 右侧固定栏：选中部件的规格/长度/颜色/连接编辑 + 安全提示。 | 现有（v2 重排版） |
| 部件列表 / 层级 | Parts List / Layers | 浮动面板「部件」分区：设计中全部型材与封板的清单，点击选中。 | 现有（移入面板） |
| 型材库 | Profile Library | 浮动面板「型材库」分区：搜索 + 系列分类 + 规格网格，选择规格进入放置。 | v2 UI |
| 规格网格 | Spec Grid | 型材库中的规格卡片网格（截面缩略图 + 尺寸 + 价格）。 | 现有（v2 重设计） |
| 系列分类 | Series Filter | 规格网格上方的分类 chips（全部 / 20 系列 / 30 系列 / 40 系列），选中后过滤网格。 | v2 UI |
| 放置条 | Placement Bar | 放置中在浮动面板显示的提示块（方向切换 + 操作说明）。 | 现有（v2 重设计） |
| 放置胶囊 | Placement Pill | 放置中悬浮在工具栏上方的深色胶囊：当前规格 + 朝向切换 + 退出；面板收起时是唯一的放置控制入口。 | v2 UI |
| 弹窗 | Modal | 清单（BOM）/ 版本历史 / AI 面板的全屏遮罩弹窗。 | 现有 |
| 横幅 | Banner | 顶部居中浮动的状态条：版本冲突、操作被拒、加载失败；游客提示为画布底部浮动条。 | 现有（v2 改浮动） |
| 用户菜单 | User Menu | 头像点击后的下拉菜单：我的设计、管理后台（管理员）、登出。 | v2 UI |

## 3. 交互与模式

| 中文 | 英文 | 解释 | 来源 |
| --- | --- | --- | --- |
| 选择工具 | Select Tool | 工具轨与工具栏中的鼠标图标工具。激活后退出放置模式（取消型材 ghost 选择），可在画布点选/拖拽/调长部件。未放置时为默认工具。 | v2 UI |
| 放置模式 | Placement Mode | 选中某规格后进入：画布内鼠标跟随 ghost，按住拖拽定长松手创建部件，可连续放置。 | 现有 |
| 幽灵预览 | Ghost Preview（Ghost） | 放置模式下跟随鼠标的半透明型材预览。 | 现有 |
| 适配视图 | Fit View / Reset View | 工具栏「适配视图」：相机与视角回到默认机位。 | v2 UI |
| 吸附 / 步进 | Snapping | 拖拽默认 10mm 步进；按住 Shift 为 1mm 丝滑步进。 | 现有 |
| 部件吸附 | Part Snapping | 移动部件时吸附到其他部件包围盒的边/中心（8mm 容差），并显示蓝色对齐辅助线。 | v2 UI |
| 多选 | Multi-select | Shift+点击切换选中态；多选后可整组拖动、右键对齐、Del 批量删除。 | v2 UI |
| 对齐菜单 | Align Context Menu | 多选 ≥2 时右键画布弹出：按 X / Y / Z 的最小边、中心或最大边对齐（单条撤销）。 | v2 UI |
| 撤销 / 重做 | Undo / Redo | 编辑会话内的命令栈（上限 100 条）；调长手势目标语义为「一次手势一条撤销记录」。 | 现有 |
| 自动保存 | Auto Save | 编辑后 1200ms 防抖自动保存到云端。 | 现有 |
| 乐观锁 / 版本冲突 | Optimistic Lock / Version Conflict | 保存携带 `baseVersion`，与其他标签页并发修改时进入冲突状态（横幅提示，可载入最新或保留本地）。 | 现有 |
| 游客模式 | Guest Mode | 未登录可编辑，仅存于本页内存；保存需登录。 | 现有 |
| 清单 | Bill of Materials（BOM） | 由设计模型生成的采购清单行（型材米数、连接件、板材等）。 | 现有 |
| AI 生成 / 修改 | AI Assist | 用自然语言生成或修改设计，走同一受约束编辑管道（可撤销）。 | 现有 |
| 版本历史 | Version History | 云端持久化的设计版本列表，可查看/回退。 | 现有 |

## 4. 使用约定

- 代码中的 `data-testid` 与类名沿用英文术语（如 `spec-grid`、`placement-bar`、`editor-toolbar`、`rail`、`parts-float`）。
- 面向用户的中文 UI 文案使用本表中文列；文档/注释中的英文对照使用本表英文列。
- 主题（浅色/深色）属于用户偏好，入口在用户设置页，**不**在编辑器主界面提供切换按钮。
